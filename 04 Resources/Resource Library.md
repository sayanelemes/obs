# Resource Library

> [!important] Принцип 80/20: 5 главных ресурсов, которые закрывают 80% программы
> Не пытайся пройти все 70+ ссылок из библиотеки. Если времени мало, опирайся на эту пятёрку:
> 1. **Сети и база ИБ:** [Professor Messer N10-009](https://www.youtube.com/watch?v=k7IOn3TiUc8&list=PLG49S3nxzAnl_tQe3kvnmeMid0mjF8Le8) + [SY0-701](https://www.youtube.com/watch?v=KiEptGbnEBc&list=PLG49S3nxzAnl4QDVqK-hOnoqcSKEIDDuv)
> 2. **Linux руками:** [Linux Journey](https://linuxjourney.com/) + [OverTheWire Bandit](https://overthewire.org/wargames/bandit/)
> 3. **Веб-уязвимости (главный фокус):** [PortSwigger Web Security Academy](https://portswigger.net/web-security)
> 4. **Локальный стенд для финального отчёта:** [OWASP Juice Shop](https://github.com/juice-shop/juice-shop)
> 5. **Комплексная практика:** [TryHackMe](https://tryhackme.com) / [Hack The Box](https://hackthebox.com)


> [!tip] Как пользоваться
> Не проходи все курсы сразу. На каждый день в roadmap указаны конкретные материалы. Здесь — библиотека альтернатив и справочников. Проверяй доступность, актуальность и бесплатность перед началом.
